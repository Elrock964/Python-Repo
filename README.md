## Password Cracker
This project demonstrates how a brute-force password attack works in a controlled educational environment. It was created to help explore cybersecurity concepts such as password security, password complexity, and why strong passwords are important.
The program systematically tests different combinations of letters, numbers, and symbols until it finds the correct password. By demonstrating how brute-force attacks operate, this project highlights why longer, more complex passwords are significantly more resistant to this type of attack.

##Educational Purpose
This project was created as an educational exercise to demonstrate cybersecurity concepts related to password security, brute-force attacks, and defensive security practices.
This software is intended only for use on systems, accounts, or password hashes that you own or have explicit authorization to test.
Unauthorized use against third-party systems or accounts may violate laws, regulations, or organizational policies. The author does not encourage or endorse illegal or unethical use of this software.
The purpose of this project is to help students and aspiring cybersecurity professionals better understand how password attacks work so they can design stronger authentication systems and encourage the use of secure passwords.
