This is a project I made that generates a random password using a string of letters, numbers, and symbols.

## Password Attack Demonstration

This is a project I made that demonstrates how a brute-force password attack works.
This program uses a brute-force attack where it repeatedly tries different combinations of letters, numbers, and symbols until it finds the correct password. I made this project because I wanted to learn how brute-force attacks work and why strong passwords are important.
