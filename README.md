## Password Attack Demonstration

This project helped me understand why having a longer and more complex password can make it harder for it to be guessed.

I made this project to see how a brute-force password attack works. The program tries different combinations of letters, numbers, and symbols until it finds the password that was entered.

**How to Use It**
1. Click on the link.
2. Enter a password to test.
3. Wait for the program to find the password.
4. Review the results.

**What the Program Does**
- Starts with short passwords
- Tries longer passwords
- Uses uppercase and lowercase letters
- Uses numbers and symbols
- Keeps trying until it finds the password

**When it finds the password, it shows:**

- Number of attempts
- Time it took
- Attempts per second
- The password

The program is limited to passwords up to 9 characters. I wanted to show how a brute-force attack works without making the program too powerful.
