This is a project I made that generates a random password using a string of letters, numbers, and symbols.

## Password Cracker
This is a project I made that is a hacking tool that guesses different accounts passwords to log into those accounts.
This program uses a brut force attack where it would repeatedly enter in different combinations of letters, numbers, and symbols until it gets the password right. 
- **Here is the link to the project: https://codepad.app/edit/tz57409p**
